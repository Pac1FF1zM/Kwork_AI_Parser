# Kwork Parser & AI Auto-Responder 🤖 💸

Интеллектуальный парсер для биржи Kwork, который находит подходящие заказы и с помощью локальной нейросети (Ollama) генерирует персонализированные черновики откликов.

## Функционал
- **🔍 Мониторинг заказов:** Парсинг биржи Kwork с использованием Selenium.
- **🎯 Фильтрация по ключевым словам:** Поиск заказов по стеку (Python, FastAPI, Telegram Bots и т.д.).
- **🧠 AI Генерация:** Автоматическое написание отклика через локальную модель **Ollama (Qwen 2.5 7B)** на основе вашего профиля.
- **📲 Telegram уведомления:** Мгновенная отправка найденного заказа и готового текста отклика в ваш Telegram.
- **🛡️ Анти-дубликат:** Система запоминает уже обработанные проекты.

## Стек
- **Python:** Основа парсера.
- **Selenium & WebDriver Manager:** Для взаимодействия с динамическим контентом сайта.
- **Ollama:** Для локального запуска нейросети.
- **Telegram Bot API:** Для уведомлений.

## Настройка

1.  **Установите Ollama:** Скачайте с [ollama.com](https://ollama.com).
2.  **Загрузите модель:**
    ```bash
    ollama pull qwen2.5:7b
    ```
3.  **Установите зависимости:**
    ```bash
    pip install selenium webdriver-manager requests
    ```
4.  **Настройте токены:**
    Отредактируйте переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в файле `parser.py`.

## Запуск
```bash
python parser.py
```
